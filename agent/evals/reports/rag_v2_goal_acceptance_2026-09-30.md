# RAG v2 目标验收与发布边界（2026-09-30）

本记录对应 `dev-v2.0` 的本轮目标：优先完成教师资料库端到端能力，再做小规模、需审核发布的权威外部来源示例。它不是生产发布批准，也不代替来源事实、署名或许可的人工/法务复核。

## 第二阶段：教师资料库

| 验收项 | 证据与边界 |
| --- | --- |
| 完整分片与定位 | 后台索引不再依赖 10 万字符的预览截断；长讲义真实数据库测试建立超过 100 个片段，末章可检索，返回资料名及章节定位。沙箱交接另用超过 10 万字符的原文验证，SHA-256 不匹配会拒绝。PDF、PPTX、Markdown、TXT、DOCX 走现有隔离解析；扫描 PDF 仍需 OCR。 |
| 教师跨项目复用及隔离 | 一位教师的资料可关联其两个项目；关联和检索在数据库层检查所有者、项目授权。合成多教师三项目测试覆盖跨教师、跨项目零召回。 |
| 明确授权和索引生命周期 | 教师在界面明确启用资料索引/模型处理；后台任务提供状态、失败原因和重试入口。重复索引保持单一版本。未授权时不调用付费 Embedding。 |
| 删除与结果引用 | 删除后来源、版本、片段与项目关联级联清理，重新检索零召回。项目结果页展示资料名与页码、幻灯片或章节定位；无来源时明确标记。仅依据选定资料时，证据缺失阻止确定性生成。 |

隔离 PostgreSQL 的教师资料库测试见 `rag_v2_stage2_teacher_library_tempdb_2026-09-29.md`；完整后台索引与长文档见 `rag_v2_stage2_worker_tempdb_2026-09-30.md`。这些测试使用合成文本和本地关键词检索，不证明真实教材事实正确、OCR、付费向量检索质量或逐句引用准确率。

## 第三阶段：权威外部来源待审示例

PostgreSQL 16 与 Python 官方文档页面可被加入精确 URL 白名单，定时或手动同步只保存 HTTP 元数据与 SHA-256。内容变化形成私有候选；管理员填写原创摘要、具体章节、版本、作者及许可，四项明确确认后才可发布。远端内容变化会撤下旧版，撤回后零召回。系统不自动抓取正文入库、不自动发布、不调用 Embedding。真实页面只在可丢弃测试库形成 `pending` 草稿，未发布真实外部知识；详见 `rag_v2_stage3_external_tempdb_2026-09-30.md` 和 `agent/docs/RAG_STAGE3_EXTERNAL_SOURCES.md`。

## 刻意保留的发布门槛

`knowledge_v2_enabled` 默认仍为 `false`；“仅依据选定资料”模式可显式走新版教师资料检索，但一般知识 API/生成仍未切换。没有足够真实标注样本，因此不宣称 Recall@5、引用正确率或延迟达到生产目标。真实来源摘要需要独立事实与许可核查；生产网络应有官方域名出口限制。任何生产读取切换、真实外部发布或付费 Embedding 调用均需按各自门槛另行执行。
