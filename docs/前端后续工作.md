# 前端后续工作

## 1. 使用方式

本文档是当前前端的工作清单。领取任务时，将条目拆成 Issue，并补充负责人、目标分支、接口依赖和验收截图。完成后勾选条目并在 Pull Request 中链接对应 Issue。

优先级定义：

- P0：形成真实产品闭环所必需。
- P1：当前页面已有入口，但行为尚未完成。
- P2：质量、性能和维护性改进。

## 2. P0：业务闭环

### 后端接入基础

- [ ] 与后端确认推演创建、计划确认、帧读取、重新生成和导出的接口契约。
- [ ] 新增统一 API Client、错误模型和 `VITE_API_BASE_URL` 配置。
- [ ] 实现加载、失败、重试、取消和离线演示状态。
- [ ] 为流式生成实现 SSE 连接、重连和用户取消。
- [ ] 保留本地 Dijkstra 模型作为演示与测试夹具。

完成标准：组件不直接拼接接口地址；网络失败有明确反馈；本地演示和真实服务状态不会混淆。

### 新建推演

- [ ] 实现知识点输入、材料上传、算法选择和基础参数表单。
- [ ] 实现表单校验、草稿保留和提交状态。
- [ ] 创建成功后进入教学计划确认页。

完成标准：刷新或返回不会意外丢失有效草稿；错误字段可定位；键盘可完整操作。

### 教学计划确认

- [ ] 展示后端生成的步骤和生成状态。
- [ ] 支持调整顺序、修改标题、重新生成单步和确认计划。
- [ ] 处理生成中断、部分成功和版本冲突。

### 教师编辑器

- [ ] 编辑节点、边、边权、讲解和帧顺序。
- [ ] 提供撤销/重做和未保存提醒。
- [ ] 实现保存、版本标记和重新生成局部内容。

### 播放与项目持久化

- [ ] 使用真实项目 ID 替换 `/project/demo/*`。
- [ ] 保存当前帧、播放速度和用户偏好。
- [ ] 最近推演从后端读取，支持空状态、分页和删除确认。
- [ ] 实现用户身份、课程选择和访问权限。

### 导出中心

- [ ] 创建导出任务并显示队列、进度、失败原因和重试操作。
- [ ] 支持下载已完成的视频或演示文件。
- [ ] 明确导出参数和预计资源消耗。

## 3. P1：现有界面行为

- [ ] “重命名推演”打开可校验的重命名对话框并持久化。
- [ ] “分享”真实写入剪贴板，并处理权限拒绝。
- [ ] “更多操作”提供有实际行为的菜单。
- [ ] “速度 1×”支持多档速度并改变播放间隔。
- [ ] 参数面板的源点、边权显示和自动讲解开关真实驱动推演。
- [ ] AI 计划步骤与算法帧建立明确映射。
- [ ] “优化本帧讲解”和“重新生成”接入真实服务或明确标为本地演示。
- [ ] 模板库实现筛选、预览、套用和空状态。

## 4. P2：工程质量

- [ ] 将 `workbench/` 拆分为 `features/simulation/`，分离图谱、检查器、播放控制、模型和适配器。
- [ ] 将 `GenerationState` 从展示组件移到领域类型文件。
- [ ] 决定 `TeachingBrief.tsx` 接入新建流程或删除。
- [ ] 增加前端 CI：安装、类型检查、测试、Lint 和生产构建。
- [ ] 增加端到端测试，覆盖主题、路由、新建、播放、保存和错误恢复。
- [ ] 增加自动化无障碍检查。
- [ ] 清理现有 Fast Refresh 警告。
- [ ] 对路由和图形模块做代码分割，将主入口包控制到合理范围。
- [ ] 增加 Error Boundary、全局错误页和遥测接入点。
- [ ] 建立依赖升级和安全扫描流程。

## 5. 推荐实施顺序

1. API 契约与服务层。
2. 新建推演和教学计划确认。
3. 参数驱动的真实互动推演。
4. 保存、最近项目和身份课程信息。
5. 教师编辑器。
6. 导出中心。
7. 架构拆分、端到端测试和性能优化。

每个阶段都应同时更新中文文档、英文 README（如适用）、测试和验收记录。
