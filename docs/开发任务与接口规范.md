- **联调节点**：每完成一个 Phase 的接口实现后联调一次

## 1. API 接口规范（前后端契约）

### 1.1 通用约定

- Base URL: `/api`
- 请求/响应格式: `application/json`
- 流式接口: `text/event-stream` (SSE)
- 错误响应格式:

```json
{
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "帧间状态不一致: f_005 的 distance_table 与 f_004 不匹配",
    "details": {}
  }
}
```

### 1.2 项目 API

#### `POST /api/projects` — 创建项目

```
Request:
{
  "title": "Dijkstra 最短路径算法",
  "input_type": "natural_language",       // natural_language | file_upload | template
  "input_content": "讲解 Dijkstra 算法...",
  "audience": "undergraduate_cs",
  "difficulty": "intermediate",
  "constraints": {                         // 可选，教师约束
    "must_cover": ["松弛操作", "贪心证明"],
    "avoid": ["复杂度的严格数学证明"],
    "style": "直观严谨",
    "estimated_duration_min": 10

Response 201:
{
  "id": "uuid",
  "title": "Dijkstra 最短路径算法",
  "status": "draft",
  "created_at": "2026-07-16T10:00:00Z"
}
```

#### `GET /api/projects` — 项目列表

Response 200:

### 1.3 生成流程 API（核心）

#### `POST /api/projects/{id}/generate` — 启动生成

```
Request:
{
  "action": "full"                       // full (完整流程) | plan_only (仅规划) | frames_only (仅帧生成)
}

Response 202:
{
  "stream_url": "/api/projects/{id}/generate/stream"
}
```

#### `GET /api/projects/{id}/generate/stream` — SSE 进度流

```
Event: progress
data: {"phase": "planning", "message": "正在检索知识库...", "pct": 10}

Event: progress
data: {"phase": "planning", "message": "已生成教学计划，等待确认", "pct": 30, "teaching_plan": {...}}

Event: progress
data: {"phase": "generating", "message": "正在生成第 5/24 帧", "pct": 50}

Event: progress
data: {"phase": "validating", "message": "质量校验中...", "pct": 90}

Event: done
data: {"phase": "done", "pct": 100, "quality_report": {...}}

Event: error
data: {"phase": "error", "message": "帧生成失败: schema 校验不通过", "details": {...}}
```

**前端处理：** 监听 SSE 事件，实时更新进度条和中间结果展示。`planning` 阶段完成后可展示教学计划让用户确认；`done` 后刷新项目详情拿到完整 DSL。

#### `POST /api/projects/{id}/regenerate` — 局部重生成

```
Request:
{
  "scope": {
    "type": "frame_range",               // single_frame | frame_range | from_frame
    "frame_ids": ["f_005", "f_006"],
    "locked_frame_ids": ["f_001", "f_003"]
  }
}

Response 202:
{ "stream_url": "/api/projects/{id}/generate/stream" }
```

#### `GET /api/projects/{id}/frames` — 获取帧列表

```
Query: ?version=1

      "visual_objects": [...],
      "state_snapshot": {...},
      "animations": [...],
      "interaction_hooks": [...],
      "quality_status": "ok",
      "is_locked": false
    }
  ],
  "version": 1
}
```

#### `PUT /api/projects/{id}/frames/{fid}` — 编辑单帧

```
Request:
{
  "title": "新的标题",
  "narration": "修改后的讲解文本",
  "visual_objects": [...],
  "state_snapshot": {...},
  "animations": [...]
}

Response 200:
{ "id": "uuid", "updated_at": "..." }
```

**约束：** `is_locked=true` 的帧不接受此请求，返回 409。

#### `POST /api/projects/{id}/frames/{fid}/lock` — 锁定/解锁帧

```
Request:
{ "is_locked": true }

Response 200:
{ "id": "uuid", "is_locked": true }
```

### 1.5 参数 API

#### `GET /api/projects/{id}/parameters` — 获取参数列表

```
Response 200:
{
  "parameters": [
    {
      "id": "uuid",
      "key": "graph_data",
      "label": "图结构",
      "param_type": "graph",
      "default_value": { "nodes": [...], "edges": [...] },
      "current_value": { "nodes": [...], "edges": [...] },
      "constraints": { "max_nodes": 10, "allow_negative_weights": false },
      "recompute_scope": "all_frames"
    }
  ]
}
```

#### `POST /api/projects/{id}/recompute` — 参数变更触发重算

```
Request:
{
  "changed_params": {
    "graph_data": { "nodes": [...], "edges": [...] }    // 新的参数值
  }
}

Response 202:
{ "stream_url": "/api/projects/{id}/generate/stream" }
```

**前端本地重算（不调此接口）：** 当参数 `recompute_scope=local` 时，前端直接在本地更新 `state_snapshot` 和受影响的帧渲染，不需要后端参与。`recompute_scope=all_frames` 时才调此接口。

## 4. DSL Schema 速查（联调关键）

双方严格对齐这份结构，避免字段名不一致导致的联调返工：

```python
# 完整数据结构参考，前后端共享

class RenderScript:
    project_id: str
    topic: str
    audience: str
    difficulty: str
    teaching_strategy: TeachingStrategy
    knowledge_graph: KnowledgeGraph
    parameters: list[Parameter]
    frames: list[Frame]
    assets: list[Asset]

class Frame:
    frame_id: str          # "f_001"
    title: str
    learning_goal: str
    narration: str
    visual_objects: list[VisualObject]
    state_snapshot: dict   # 自由 JSON
    animations: list[Animation]
    interaction_hooks: list[InteractionHook]
    checks: list[Check]

class VisualObject:
    id: str                # "node_a"
    type: str              # node|edge|array|linked_list|tree|graph|table|code_block|...
    label: str
    position: list[float]  # [x, y]
    style: dict            # {"color": "#4A90D9", "size": 40}
    # type 不同时会有额外字段，如 edge 有 from/to

class Animation:
    type: str              # appear|disappear|highlight|transform|move|update_value|...
    target: str            # 对应 VisualObject.id
    duration_ms: int
    params: dict           # 动画参数，如 {"from": 12, "to": 9}

class InteractionHook:
    type: str              # slider|select|switch|button
    param: str             # 绑定的参数 key
    range: list[float] | None   # slider 时的范围

class Parameter:
    key: str
    label: str
    param_type: str        # number|string|boolean|enum|graph|array
    default_value: dict
    current_value: dict
    constraints: dict
    recompute_scope: str   # "local" | "all_frames"

class Check:
    type: str
    rule: str              # "dist[B] + w(B,C) >= dist[C]"
```
