# ADR 0003：将模型生成代码移出带凭据进程

- 状态：Accepted
- 日期：2026-09-05

## 背景

静态 AST 校验可以阻止常见危险 import，但不能作为执行任意模型代码的完整安全边界。API 进程持有数据库、Redis、对象存储和模型凭据，一旦逃逸影响范围过大。

## 决策

API 只创建持久化导出任务；Render Worker 负责生成和静态校验脚本，再经只包含任务文件的共享目录交给 Render Sandbox。沙箱无网络、无数据库/Redis/LLM/MinIO 凭据，根文件系统只读，丢弃 capabilities，并限制 CPU、内存、PID、时间、文件数和总字节。迟到结果只有在 lease/attempt 仍有效时才能写入终态。

## 结果

- 模型代码不能直接读取服务凭据或访问外网；
- API 重启不会丢失已接受任务，Worker 崩溃后可按 lease 重领；
- 取消、超时和配额超限会终止进程组；
- 当前常驻沙箱与共享卷仍弱于每任务临时容器，后者是公开多租户部署前的后续项。

## 被否决方案

- 只做字符串/AST 黑名单：无法覆盖运行时逃逸；
- 在 API 子进程执行：仍共享宿主网络、文件和环境；
- 将 Docker Socket 挂入 Worker 动态创建容器：扩大了控制面权限，首版采用预置无凭据沙箱。
